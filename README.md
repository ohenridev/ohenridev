## Sobre mim

Sou Analista de TI em transição para o Desenvolvimento de Software, focado em construir uma base sólida em programação, tecnologias web e Engenharia de Software.

Meu interesse pelo desenvolvimento vem de uma mentalidade prática: compreender problemas, explorar soluções e criar ferramentas que melhorem processos e atividades do dia a dia.

Atualmente, estou fortalecendo meus conhecimentos em JavaScript e desenvolvimento web, avançando gradualmente para TypeScript, Node.js, desenvolvimento backend e aplicações Full Stack.

- **Foco atual:** JavaScript, lógica de programação e desenvolvimento web.
- **Estudando:** TypeScript, Node.js, APIs REST e bancos de dados relacionais.
- **Desenvolvendo:** Projetos práticos voltados à resolução de problemas reais.
- **Objetivo:** Evoluir para Engenheiro de Software, com fundamentos técnicos sólidos e capacidade de resolver problemas.

> "Cada linha de código é um passo para compreender o problema e construir uma solução melhor."
